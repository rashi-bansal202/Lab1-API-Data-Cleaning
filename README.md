
# Lab 1: API-Based Data Cleaning & Validation Toolkit

**Course:** Data Handling, Visualization & Feature Engineering  
**Program:** BCA — Artificial Intelligence & Data Science

## Aim
To collect data from an API, clean and validate it, detect outliers, create visualizations, and generate a data profiling report.

## Tools and Libraries
- Python
- Google Colab
- Pandas
- Requests
- NumPy
- Matplotlib
- YData Profiling

## Objectives
1. Fetch real-world data using an API.
2. Inspect and clean the dataset.
3. Handle missing values and duplicate records.
4. Validate data quality.
5. Detect outliers using the IQR method.
6. Visualize data using charts.
7. Generate an automated profiling report.

## Project Files
- `Lab1_API_Data_Cleaning.ipynb` — Python notebook
- `raw_products.csv` — Original dataset
- `cleaned_products.csv` — Cleaned dataset
- `price_distribution.png` — Price distribution histogram
- `price_outliers.png` — Price outlier box plot
- `data_profile_report.html` — Profiling report

## Result
This project demonstrates an API-based data preprocessing workflow, including data cleaning, validation, outlier detection, visualization, and profiling.
